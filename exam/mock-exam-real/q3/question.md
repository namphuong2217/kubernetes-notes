# Question 3 — Sidecar Container Sharing a Log Volume

## Background

An existing Deployment named **apache-web** is running in the **default** namespace.

Your task is to update the Deployment by adding a sidecar container that continuously reads the application log generated by the main container.

---

## Tasks

1. Update the existing Deployment:

   ```
   apache-web
   ```

2. Add a sidecar container with:

   - Name:

     ```
     log-shipper
     ```

   - Image:

     ```
     busybox:stable
     ```

3. Configure the sidecar container to run:

   ```bash
   /bin/sh -c "tail -f /var/log/apache-web.log"
   ```

4. Create a shared volume using:

   ```
   emptyDir
   ```

5. Mount the shared volume to:

   ```
   /var/log
   ```

   in both the main container and the sidecar container.
