# Lab Requirements

⚠️ This lab must be completed on a dedicated KodeKloud environment where no CNI has been installed yet.

Recommended environment:

- KodeKloud CKA Lab: Install a CNI
- A fresh Kubernetes cluster initialized with kubeadm
- No existing CNI plugin

Reason:

This exercise installs a cluster-wide CNI plugin. The installation cannot be reliably reset with a cleanup script and will affect subsequent labs.

This lab should be performed independently from Questions 1–7.
